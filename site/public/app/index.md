# Clarity Writing Editor

The Clarity Writing Editor is a private browser application at https://clarity.addy.ie/app/. Analysis runs locally in the browser and the draft is not uploaded.

It provides:

- transparent flags for common AI-writing phrases, vocabulary, and formulaic structures;
- readability checks for difficult sentences, passive voice, weakeners, and simpler alternatives;
- broader Clarity prompts about reader intent, source fidelity, supported claims, openings, paragraph development, endings, and voice;
- descriptive signals that never change the surface-pattern score;
- a copyable agent prompt with line-specific findings;
- local draft persistence on the current device.

The editor is a writing aid, not an authorship detector or fact verifier. A finding is a prompt for editorial judgment, not proof that AI wrote the text.
